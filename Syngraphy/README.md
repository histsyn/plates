# Syngraphy — illustrations for the 書史 - Syngraphy weekly column

The Facebook column **書史 - Syngraphy** (`https://www.facebook.com/hist.syngraphy`) and its blog
(histsyn.com) run one post every Monday at 08:00 HKT. These are the illustrations used by that
column, served over GitHub Pages:

**`https://histsyn.github.io/plates/Syngraphy/images/<file>`**

Why here: the Blogger API cannot upload media, and GitHub Pages serves every file with
`Access-Control-Allow-Origin: *`, so the same URL works in a blog post and in a script that later
reads the pixels. The same reason as the rest of this repository.
