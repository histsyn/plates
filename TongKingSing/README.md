# TongKingSing — 唐廷樞 (1832–1892) plate set

Nine production plates for the biography of Tong King-sing, published at
<https://www.histsyn.com/2026/11/tong-king-sing-18321892-from-comprador.html>.

Every plate is a **crop of the page with the cited sentence framed in amber**; each frame was read back at its final bytes before publication (§6B gate, 2026-11-23/24). The `*.boxes.json` files are the painter's own measurements — the phrase each frame encloses, the number of printed lines it carries, and the crop it came from.
